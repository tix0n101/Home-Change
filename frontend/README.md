# Home-Change — фронтенд

Это «лицо» сайта: страницы, которые видит пользователь в браузере.
Написан на чистых **HTML + CSS + JavaScript** — без фреймворков и без установки зависимостей.

## Что внутри

```
frontend/
├── index.html        главная страница (шапка и контейнер)
├── css/
│   └── styles.css    все стили сайта
└── js/
    ├── api.js        запросы к бэкенду и хранение токена
    └── app.js        вся логика интерфейса
```

## Экраны

- **Вход / Регистрация** — получение токена и вход в систему.
- **Объявления** — список активных квартир с фильтрами по городу, комнатам и цене.
- **Подбор** — автоматические совпадения для ваших квартир (с процентом совпадения).
- **Заявки** — входящие и отправленные заявки на обмен (принять / отклонить / отменить).
- **Сообщения** — переписка с другими пользователями.
- **Мои квартиры** — добавление, изменение и удаление своих объявлений.

## Как запустить

Сначала должен быть запущен **бэкенд** (папка `backend`):

```powershell
cd backend
python app.py
```

Затем откройте фронтенд одним из способов:

### Вариант 1 (рекомендуется) — мини-сервер для статики

Из папки `frontend`:

```powershell
python -m http.server 8080
```

И откройте в браузере: <http://127.0.0.1:8080>

### Вариант 2 — просто открыть файл

Дважды кликните `frontend/index.html`. Тоже работает, потому что бэкенд разрешает
запросы с любых источников (CORS).

## Настройка адреса бэкенда

Если сервер работает не на `127.0.0.1:5000`, поменяйте адрес в начале файла
`js/api.js`:

```js
const API_BASE = "http://127.0.0.1:5000";
```
